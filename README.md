## Professional Overview (Cyber Security Focus)
This repository presents **Cyber Security projects** developed during an intensive training program **sponsored by Santander**, with more than **40 hours of hands-on and theoretical content**.

The course covered fundamental and practical concepts of **offensive and defensive security**, combining **ethical hacking techniques**, **Python scripting**, and **real-world attack simulations**, always with an educational and ethical focus.

⚠️ **All projects in this repository were developed strictly for educational purposes and security awareness.**

Throughout the training, I studied and practiced:

- Fundamentals of Cyber Security
- Penetration Testing (Pentest) and Vulnerability Assessment
- Brute Force Attack Simulation using **Medusa** and **Kali Linux**
- Social Engineering: how attackers exploit human behavior
- Man-in-the-Middle (MITM) attacks and mitigation techniques
- Malware concepts and defensive strategies
- Understanding ransomware behavior in practice
- Phishing attacks and prevention methods
- Ethical hacking mindset and defensive countermeasures

## Projects Developed

### Project 1: Phishing Simulation with Kali Linux

#### Description
This project demonstrates how phishing attacks are created using tools available in **Kali Linux**, focusing on understanding attacker techniques in order to improve defensive strategies.

#### Key Learning Points
- How phishing pages are structured
- Common social engineering techniques
- Importance of user awareness and security training
- Detection and prevention strategies

⚠️ **This project is strictly educational and should never be used for malicious purposes.**

### Project 2: Ransomware Simulation with Python

#### Description
In this project, I developed a **basic ransomware simulation** using Python, including:
- A file **encryption script**
- A file **decryption script**

The objective was to understand how ransomware operates internally, enabling better detection, response, and prevention strategies.

#### Key Learning Points
- File encryption and decryption concepts
- How ransomware affects systems
- Importance of backups and security policies
- Defensive measures against ransomware attacks

⚠️ **This project is strictly educational and intended for learning and defensive awareness only.**

### Projeto 2: Simulação de Ransomware com Python

#### Descrição
Neste projeto foi desenvolvido um **ransomware simulado** em Python, contendo:
- Um script de **criptografia de arquivos**

O objetivo foi compreender o funcionamento interno desse tipo de ameaça para melhorar estratégias de defesa e resposta a incidentes.

#### Principais Aprendizados
- Conceitos de criptografia e descriptografia
- Impacto de ransomware em sistemas
- Importância de backups e políticas de segurança
- Medidas preventivas contra ataques de ransomware
